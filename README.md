# Галлы: последний пир

Небольшая фанатская игра про Астерикса и Обеликса в жанре survival arena. Отбивайтесь от римлян, собирайте усиления и помогите деревне дождаться пира.

```sh
npm run dev
```

Node.js 24, зависимостей нет. Чтобы открывать `index.html` напрямую, один раз выполните `npm run generate`.
