# Галлы: последний пир

Небольшая фанатская игра про Астерикса и Обеликса в жанре survival arena. Отбивайтесь от римлян, собирайте усиления и помогите деревне дождаться пира.

Откройте `index.html` или запустите проект локально по инструкции в [технической документации](documentation.md).

Играйте с удовольствием!
