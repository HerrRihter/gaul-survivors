# Техническая документация

## О проекте

«Галлы: последний пир» — локальная браузерная survival arena по мотивам историй об Астериксе и Обеликсе. Игрок выбирает героя, сражается с волнами противников, собирает опыт и улучшения. Сетевой режим и серверное сохранение не используются; постоянный прогресс хранится в браузере.

## Быстрый запуск

Требуется Node.js 24. Установка npm-пакетов не нужна.

```sh
npm run dev
```

Откройте адрес, напечатанный сервером. Альтернативно можно открыть `index.html` в браузере: для режима `file://` используются сгенерированные скрипты из `runtime/`. Для обычной разработки предпочтителен локальный HTTP-сервер.

Основные команды:

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Запустить локальный HTTP-сервер. |
| `npm run generate` | Обновить производные файлы анимационных данных и скрипты для `file://`. |
| `npm test` | Проверить актуальность генерации и запустить набор тестов. |
| `npm run build` | Собрать сайт для публикации в `_site/`. |

После изменения исходников запускайте `npm run generate`; тесты и сборка проверяют, что сгенерированные файлы не устарели.

## Структура проекта

| Путь | Назначение |
| --- | --- |
| `src/main.js` | Браузерная точка входа и создание игровой сессии. |
| `src/app/` | Связь подсистем, игровая сессия и переходы между состояниями. |
| `src/core/` | Общие сервисы, включая ввод, звук и игровой цикл. |
| `src/systems/` | Боевая логика, волны, улучшения и сохранение. |
| `src/entities/`, `src/world/` | Герои, противники, арены и деревня. |
| `src/rendering/`, `src/ui/` | Canvas-отрисовка, загрузка графики и интерфейс. |
| `src/pages/` | Логика страниц просмотра легиона и карты. |
| `data/` | Игровые определения, расписания волн и исходные данные анимации. |
| `assets/runtime/` | Ресурсы, загружаемые игрой. |
| `assets/source/` | Художественные исходники, промпты и метаданные. |
| `styles/` | Стили игры. |
| `tools/` | Сборка, генераторы, локальный сервер и вспомогательные проверки. |
| `tests/` | Проверки игровой логики, загрузчиков, сборки и публикации. |
| `previews/` | Локальные страницы визуального просмотра и измерений. |

### Источники данных и генерация

- Первичные описания границ кадров находятся в `data/animations/*-layout.json`; генератор создаёт соответствующие JS-модули. Проверять и обновлять их можно через `node tools/generate-layouts.cjs --check` и `node tools/generate-layouts.cjs`.
- `tools/generate-file-bundles.cjs` собирает зависимости ES-модулей в классические скрипты для запуска через `file://`. Редактировать следует исходники в `src/`, а не созданные файлы `runtime/`.
- Характеристики героев и противников задаются в `data/characters/heroes.js` и `data/enemies/units.js`; расписание волн — в `data/enemies/waves.js`; момент события попадания анимации — в `data/animations/action-timing.js`.
- Звуковые события вызываются игровыми системами по логическим именам; соответствие им аудиофайлов определяется в `src/core/audio.js`. Публикуемые аудиоресурсы перечислены отдельно в `tools/publication-manifest.cjs`.

## Запуск игры и механики

- Управление: WASD или стрелки; на сенсорном экране — касание и движение пальцем. `Escape` или `P` ставит игру на паузу.
- Уникальные умения: Q и E или две кнопки справа внизу; на телефоне можно одновременно двигаться и нажимать умение. Перезарядки и эффекты останавливаются на паузе. «Кузнечная закалка» Автоматикса бесплатно повышает постоянную «Крепкую кожу» на один ранг до её предела 3.
- При повышении уровня предлагаются четыре разных улучшения (клавиши 1–4). Пока доступны ранги, гарантированы варианты оружия героя и активного умения. Каждое активное умение имеет три ранга на текущий забег; усиление применяется со следующей активации. Улучшение закалки Автоматикса также сразу сокращает текущую перезарядку на 6 секунд.
- Атаки происходят автоматически по направлению последнего движения. Опыт открывает выбор усиления; еда восстанавливает здоровье.
- Цель забега — выжить и победить финального противника. Музыку и эффекты можно отключить и настроить в меню.
- Рекорды, настройки звука и постоянный прогресс сохраняются в `localStorage` этого браузера и устройства.

Основные игровые состояния и логика собраны в `src/app/` и `src/systems/`; визуальное представление — в `src/rendering/`. Точные параметры врагов, волн, столкновений и прогрессии следует сверять с исполняемыми определениями и тестами, а не поддерживать отдельную копию чисел в этом документе.

## Тесты и непрерывная интеграция

Запустить полный набор локально:

```sh
npm test
```

`tools/test-all.cjs` сначала проверяет производные файлы, затем запускает тесты игровой логики, анимаций, звука, отрисовки, локального запуска и сайта. GitHub Actions использует Node.js 24 и выполняет ту же проверку перед сборкой и публикацией.

Для отдельных проверок можно запускать нужный файл напрямую, например:

```sh
node --experimental-vm-modules tests/test.cjs
node --experimental-vm-modules tests/test-rendering.cjs
node --experimental-vm-modules tests/test-site.cjs
```

## Сборка и публикация

Список страниц и ресурсов сайта задаётся в `tools/publication-manifest.cjs`. Сборка проверяет наличие перечисленных файлов и копирует только их в `_site/`; вспомогательные страницы и исходные материалы туда не попадают.

```sh
npm run build
```

GitHub Pages публикуется workflow-файлом `.github/workflows/deploy-pages.yml`: после успешных тестов он собирает `_site/` и развёртывает содержимое. Для обновления публикации отправьте изменения в одну из настроенных веток или запустите workflow вручную через GitHub Actions.

Опубликованные страницы:

| Файл | Назначение |
| --- | --- |
| `index.html` | Игра. |
| `legion-preview.html` | Просмотр противников и разведданные. |
| `village-preview.html` | Просмотр карты и её элементов. |

## Страницы для разработки

Страницы внутри `previews/` — локальные инструменты, а не дополнительные страницы опубликованной игры:

- `animation-preview.html` — просмотр персонажей, кадров и анимационных действий.
- `animation-audit.html` — визуальная проверка кадров.
- `art-preview.html` и `hero-preview.html` — галереи графики и героев.
- `performance.html` — измерение производительности сцены.

Страницы разведданных и карты, напротив, опубликованы и доступны из игрового меню.
